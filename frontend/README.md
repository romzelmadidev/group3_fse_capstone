# Retail Banking SPA (Frontend)
> **Stack:** React 18, Vite, Tailwind CSS, Lucide Icons

This Single Page Application provides interfaces for **Customer**, **Teller (Ledger)**, and **Admin** roles.

## Quickstart

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
*Runs on `http://localhost:3000`*

### 3. Build for Production
```bash
npm run build
```
